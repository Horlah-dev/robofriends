# RoboFriends

A React app that displays a searchable list of robot friends. Type in the search box to filter the cards by name.

## Features

- Displays robot friend cards with names and email addresses
- Filters the cards as you type
- Responsive layout

## Built with

- React
- JavaScript
- CSS
- [RoboHash](https://robohash.org/) for robot images
